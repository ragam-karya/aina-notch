Cara ngobrol

Tahan tombol bicara untuk satu pertanyaan. Tekan sekali (atau ucapkan "Hey aina") untuk mulai ngobrol: aina terus mendengarkan, kamu bisa memotongnya kapan saja, dan sesi berakhir saat kamu pamit, tekan Esc, atau diam sebentar. Untuk melihat layar, aina tetap memakai Claude.

Mesin realtime memakai OpenAI API key dan kira-kira $0,02–0,04 per menit ngobrol (gpt-realtime-2.1-mini). Suara hanya dikirim saat kamu menahan tombol atau selama sesi ngobrol, dan tidak disimpan.

Kontrol komputer

Contoh: "buka Spotify, putar lofi" atau "cari berita keuangan hari ini lalu buat ringkasannya". aina minta izin dulu sebelum mengirim, membeli, atau menghapus sesuatu, dan tidak pernah mengetik kata sandi. Esc menghentikannya.

Berlaku untuk "kerjakan untukku" dan aina latar belakang. Kalau mati, aina bertanya dulu lewat suara setiap kali mau membuat, mengedit, memindah, me-rename, atau menghapus sesuatu di luar folder kerjanya. Jawab "boleh", "boleh semua" (untuk sisa tugas itu) atau "jangan". File yang dihapus selalu masuk Recycle Bin, dan folder sistem, program, serta AppData tidak pernah disentuh.

Dengan ekstensi aina di Chrome atau Edge, aina membaca halaman web secara langsung, jadi klik di website lebih tepat dan lebih hemat. Ekstensi ini hanya tersambung ke aina di komputer ini lewat kode di bawah. Kalau browser sudah menawarkan ekstensi aina, aktifkan saja lalu lanjut ke langkah 4.

  1. Buka chrome://extensions (atau edge://extensions) di browser.
  2. Nyalakan Developer mode.
  3. Klik Load unpacked, lalu pilih folder ekstensi.
  4. Klik ikon aina di toolbar browser, lalu masukkan kode ini. Tanda ON artinya sudah tersambung.

Aplikasi kerja

aina bisa memakai Gmail, Google Calendar/Drive/Docs/Sheets/Tasks, Outlook, Teams, Notion, Linear, Jira, ClickUp, HubSpot, Salesforce, Dropbox, GitHub dan Slack untukmu, misalnya "cek email penting hari ini" atau "jadwalkan meeting besok jam 10 dengan Sari". Koneksinya lewat Composio: daftar gratis di composio.dev, salin key-nya ke sini (key Composio Connect ck_… dari For You → Settings → Sessions & API Key, atau Project API key ak_…), Simpan, lalu nyalakan aplikasinya.

Aplikasi kerja khusus akun berbayar (langganan, atau setelah membeli Top-Up). Untuk sekarang baru aplikasi Google; yang lain menyusul, ditandai Segera.

Login aplikasimu disimpan di server Composio, bukan di PC ini, dan isi email, kalender, atau dokumen yang dipakai aina lewat server Composio. Membaca tidak perlu izin. Sebelum mengirim, membuat, mengubah, atau menghapus sesuatu, aina bertanya dulu, kecuali kamu mengizinkan "mengatur tanpa bertanya" di Kontrol komputer.

Nyalakan saklar aplikasi yang boleh dipakai aina. Kalau belum tersambung, halaman login-nya terbuka di browser. Mematikan saklar membuat aina berhenti memakainya, tapi akunnya tetap tersambung. Pakai Putuskan untuk menghapus sambungannya.

Login atas nama aina

Biasanya halaman izin Google, Slack, dan lainnya menampilkan "Composio". Pakai OAuth app milikmu sendiri supaya yang tampil nama aplikasimu (misalnya aina). Hanya untuk Project API key (ak_…). Buat OAuth app di console penyedianya, isi redirect URI di bawah, lalu tempel Client ID dan Client Secret di sini. Secret-nya dikirim ke Composio dan tidak disimpan di PC ini.

Notch

Arahkan mouse ke notch di tengah atas layar untuk melihat jam, timer, lagu yang diputar, tugas latar belakang yang jalan, pengingat, dan pintasan di bawah ini. Bilang "timer 25 menit", "pomodoro", "ingetin aku jam 3 meeting", atau "skip lagu". Untuk fokus di folder atau upload ke Google Drive, bilang "fokus di folder ini" atau "upload file ini ke Drive", lalu taruh folder atau file-nya di notch.

Lirik tersinkron diambil dari LRCLIB (lrclib.net), layanan lirik gratis. Untuk itu aina mengirim judul, artis, album, dan durasi lagu yang sedang diputar ke LRCLIB. Liriknya hanya disimpan di memori selama lagu itu diputar.

Pomodoro

Bilang "pomodoro" atau tekan Mulai di halaman timer notch. Perubahan di sini berlaku mulai fase berikutnya.

Kalau mati, fase berikutnya menunggu di notch sampai kamu tekan Mulai.

Pengingat

Halaman Pengingat di notch menggabungkan pengingat lokal, acara Google Calendar, dan jadwal salat. Halaman itu selalu dibuka dengan tampilan yang kamu pilih di sini; tombol tampilan di notch hanya untuk melihat sebentar.

Acara dari kalender yang kamu centang di Google Calendar ikut tampil. Sambungkan dan nyalakan Google Calendar di Aplikasi kerja. Pengingat lokal tetap di PC ini kecuali kamu memilih Google saat membuatnya. Kalau sinkron gagal, aina tidak mencoba lagi sendiri: tekan Coba lagi di notch.

Jadwal resmi Kemenag (Imsak sampai Isya) dari api.myquran.com, diambil sebulan sekali lalu disimpan di PC ini. Yang dikirim hanya kota yang kamu pilih.

Hotkey & perilaku

Dikenali langsung di laptop ini oleh pengenal suara Windows, tanpa internet. Tidak ada suara yang dikirim atau disimpan sampai kamu memanggil aina. Selama aktif, mikrofon tetap terbuka (ikon mikrofon Windows tampil) dan memakai sekitar 40 MB RAM. Beri jeda sebentar setelah "Hey aina", tunggu bunyi, baru bicara.
